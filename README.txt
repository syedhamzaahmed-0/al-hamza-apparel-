AL HAMZA APPAREL WEBSITE FILES

Files:
- index.html — website structure and product catalogue
- style.css — responsive design and styling
- app.js — product filters, custom order form and WhatsApp enquiry

HOW TO ADD TO GITHUB:
1. Open your al-hamza-apparel- repository.
2. Upload all three files into the same root folder as index.html.
3. Make sure the HTML links say ./style.css and ./app.js (already set).
4. Commit changes, then open your GitHub Pages website and refresh.
